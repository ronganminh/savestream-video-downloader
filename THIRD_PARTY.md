# Third-party components

This repository integrates with independently maintained open-source projects:

- `yt-dlp` (installed as a Python dependency; see the upstream project for its license and third-party notices).
- `imputnet/cobalt` (optional/self-hosted container, AGPL-3.0; this repository talks to it over HTTP and does not vendor its source).
- `Evil0ctal/Douyin_TikTok_Download_API` (optional/self-hosted service, Apache-2.0 at the time this integration was written; not vendored here).

Review upstream licenses and notices before production distribution or modification of those upstream projects.
